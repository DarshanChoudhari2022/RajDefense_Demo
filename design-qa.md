# Cinematic website review

Final result: passed

Compared the five supplied reference screenshots with the running site at 1440 × 900 and 390 × 844. The Raj design uses an aerial hero with a transparent navigation bar, a rotor detail, a hangar reveal, a condensed maritime headline and four expandable programme cards. The master flight image and existing product information carry through the redesign. The new videos use illustrative stills with animated camera movement and light.

The desktop review led to wider text columns for the propulsion and maritime headlines. The mobile review led to a shallower crop for the hero aircraft and a shorter briefing link. The gallery controls wrap at narrow widths. The interactive viewer stage now contains its reference image so the image cannot intercept clicks on the controls.

Verified zero document overflow at 320, 390, 680 and 1440 CSS pixels. Chrome played and paused each background film, opened the overview film, expanded the maritime card and switched the aircraft viewer into exploded mode. With reduced motion enabled, all four background players kept their still frames until requested. The browser reported no JavaScript errors.
